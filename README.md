# Green-Leaf

## Description

The Customer class represents a simple data model used to store customer information, including the customer’s name, email address, and mailing address.

This application also includes controller methods that handle user authentication and customer data submission using Spring MVC:

* The **login endpoints (/login)** display a login form and process user credentials. If the username and password match predefined values, the user is redirected to a welcome page with a success message. Otherwise, an error message is shown and the login page is redisplayed.

* The **customer endpoints (/customer)** display a form for entering customer information and handle form submission. When the form is submitted, the **customer** data is bound to a Customer object and displayed on a result page.

Overall, this code demonstrates basic Spring MVC concepts such as request mapping, form handling, model attributes, and simple authentication logic.
